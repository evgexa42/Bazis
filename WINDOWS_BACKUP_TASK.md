\# Настройка ночного бэкапа SQLite на Windows



\## Подготовка

1\. Убедитесь, что виртуальное окружение создано в `.venv` (или `venv`) в корне проекта и содержит все зависимости (`pip install -r requirements.txt`).

2\. Проверьте, что файл `database.db` находится в корне проекта.

3\. При первом запуске создайте папки `backups` и `logs`, если их ещё нет — скрипт сделает это автоматически.



\## Планировщик заданий (Task Scheduler)

1\. Откройте \*\*Task Scheduler\*\* → \*\*Create Task...\*\*.

2\. Вкладка \*\*General\*\*:

&nbsp;  - Name: `SQLite Nightly Backup`.

&nbsp;  - Security options: выберите пользователя, который имеет доступ к папке проекта.

&nbsp;  - Отметьте \*\*Run whether user is logged on or not\*\*.

&nbsp;  - Включите \*\*Hidden\*\* для скрытого выполнения.

3\. Вкладка \*\*Triggers\*\*:

&nbsp;  - \*\*New...\*\* → \*\*Daily\*\* → Start: `03:00:00` → OK.

4\. Вкладка \*\*Actions\*\*:

&nbsp;  - \*\*New...\*\* → Action: \*\*Start a program\*\*.

&nbsp;  - Program/script: `cmd`.

&nbsp;  - Add arguments: `/c ""%~dp0run\_backup.bat""`.

&nbsp;  - Start in: путь к корню проекта (например, `C:\\Projects\\Bazis`).

5\. Вкладка \*\*Conditions\*\* и \*\*Settings\*\*: при необходимости снимите ограничения на питание/простоев.

6\. Нажмите \*\*OK\*\* и введите пароль учётной записи (если потребуется).



\## Как проверить работу задачи

\- В окне Task Scheduler выберите задачу → \*\*Run\*\* и убедитесь, что новая копия появляется в папке `backups` вида `database\_YYYY-MM-DD\_HHMM.db`.

\- Откройте `logs/backup.log` и проверьте наличие записей о создании резервной копии или возможных ошибках.

\- После нескольких запусков убедитесь, что сохраняется не более 14 файлов бэкапов и старые записи удаляются.
